# 小店订单计价（第 24 课的玩具仓库）

一个故意埋了 bug 的小项目，给编码 Agent 练手用。**demo 会把它复制到临时目录再修改，这里的模板永远不会被改动。**

- `pricing.py`：订单计价。计价顺序：商品小计 → 会员折扣 → 满减券 → 运费。**所有金额的单位都是"分"（整数）**。
- `receipt.py`：小票格式化，里面的函数还没实现，是 harness 演示用的"待开发功能"。
- `tests/`：验收测试。运行：`python -m pytest -q`

业务规则：

| 规则 | 说明 |
|---|---|
| 会员折扣 | 普通会员不打折，银卡 95 折，金卡 9 折；结果四舍五入到分（0.5 分进位） |
| 满减券 | "满 X 减 Y"：金额**达到** X（大于等于）就能用；减完不低于 0 |
| 运费 | 按折扣、用券之后的金额判断：满 99 元包邮，否则收 8 元 |
