## How to Read This List

There's a lot here, and you don't need to read all of it. Pick a route based on your role first. In each group's table, the "Order" column gives the suggested reading order (items marked ⭐ are must-reads for that group).

| Route | Who it's for | Suggested reading | Estimated time |
|---|---|---|---|
| **A. One-hour intro** | You just finished Part 1 of the course | A1 → A2 → B1 → G2 | About 1 hour |
| **B. An engineer's week** | Developers taking an agent to production | Route A + C1 → D4 → E1 → E2 → I2 → J1 → J2 → the remaining ⭐ items in groups A–M; after Part 3, add N1 → O1 → U1 → S1; after Part 4, add W1 → X1 → Y1 → AA1 | 1 hour a day for about a week |
| **C. Security lead** | People who do security reviews and red teaming | All of group I (in order) + C4 + H2 + group P + O6 + U3 → U4 | About a day |
| **D. Platform engineer / architect** | People who own multi-tenant platforms and infrastructure | Groups E + F + G + L + D4 + P1 → P6 → P7 + group Q; for production deployment, add groups W, X, and AB | About two days |
| **E. Eval lead** | People who own quality and the eval system | All of group J + B4 + D3 + groups R and S + T2 | About a day |
| **F. Retrieval and memory engineer** | People building knowledge-base Q&A or personalized assistants | H1 → group N → B6 → B7 → group O | About a day |
| **G. Optimization and the ML loop** | People responsible for making agents keep improving (data → evals → optimization) | R1 → R2 → S1 → S2 → Q1 → group T → S9 | About a day |
| **H. Coding agents and long tasks** | People building coding agents or long-running agents | U1 → D7 → U3 → U4 → S8 → P5 → I12 → U5 | About half a day |
| **I. Frontier and research** | People doing agent research or tracking the frontier | All of group V + S1 + S7 + J5 | About a day |
| **J. Production** | People who have finished Part 4 and will deploy and operate an agent service | W1 → F1 → W3 → X1 → X5 → Y1 → Y2 → Z1 → Z2 → AA1 → AA2 → AB1 → AB2 → AB3 | About a day |

> 💡 How to read a paper: start with the abstract and conclusion, then look at the figures and tables, and only then read the method details. For most papers on this list, you only need to understand what concept it introduced and why that concept matters.
